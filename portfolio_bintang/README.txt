PORTOFOLIO BINTANG Irsyad ARYASATYA

CARA MELIHAT
1. Ekstrak file ZIP.
2. Buka folder portfolio_bintang.
3. Klik dua kali index.html atau buka melalui browser.

SERTIFIKAT
- 9 sertifikat gambar sudah dimasukkan ke assets/certificates.
- Sertifikat Kompetensi Digital MVC & Laravel 11 tersedia sebagai PDF beserta preview.
- Klik tombol View Certificate / View PDF untuk membuka tampilan besar.
- Filter dan kolom pencarian dapat digunakan pada bagian My Certificates.

FOTO PROFIL
- Foto profil Bintang sudah dipasang di halaman utama.
- File foto: assets/profile/bintang-profile.webp.
- Untuk mengganti foto, ganti file tersebut dengan foto baru dan pertahankan nama file yang sama.

MENGATUR KONTAK
1. Buka index.html dengan editor teks.
2. Cari baris: const CONTACT = { github: "", email: "", linkedin: "" };
3. Isi URL GitHub, email publik, dan URL LinkedIn.

CATATAN
Bagian profil dan skill masih dapat disesuaikan lagi. Skill ditampilkan sebagai area minat awal, bukan klaim level kemampuan. Link kontak sengaja belum diaktifkan karena tautan/alamatnya belum diberikan.
